# يمن كريبتو — المرحلة الرابعة: تجهيز النشر

تحتوي الحزمة على تطبيق تجريبي عربي، تسجيل حسابات، لوحة مدير، وملفات Docker للنشر.

## التشغيل المحلي المعتاد
- ثبّت Node.js 20 أو أحدث.
- نفّذ `npm install`.
- عيّن `ADMIN_SETUP_TOKEN` في متغيرات البيئة.
- نفّذ `npm start` وافتح `http://localhost:3000`.

## النشر عبر Docker
راجع ملف `DEPLOYMENT.md`، واستخدم `compose.yaml` و`.env.example`.

## مهم
المشروع غير منشور على الإنترنت تلقائيًا. تحتاج خادمًا أو خدمة استضافة ونطاقًا وإعداد HTTPS. لا تستقبل أموالًا حقيقية: كل وظائف الإيداع والسحب والتداول معطلة، وهذه الحزمة ليست منصة مالية جاهزة للإنتاج.
